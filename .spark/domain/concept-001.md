# studylog-agent

- Track learning progress and study sessions
- Log knowledge acquisition and skill building
- Monitor study patterns and effectiveness
- Write tiles to PLATO with explicit schema

## The Dojo Connection
Learning while producing. The agent tracks its own growth as it helps others grow.
Every study session produces knowledge that goes into PLATO.
